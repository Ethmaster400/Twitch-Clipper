Claud Clipper

Claud Clipper is a personal tool that turns highlight clips from Twitch streamers who have given permission into vertical videos with captions, and uploads them to the operator's own TikTok and YouTube accounts.

How it works

  1. It finds popular recent clips from an approved list of Twitch streamers.
  2. It reformats each clip to 9:16, keeps the streamer's webcam visible and adds captions.
  3. The account owner signs in with TikTok (Login Kit) once. Finished videos are then sent to that account's TikTok inbox as drafts, or posted directly, using the Content Posting API.

It only ever uploads to the account that signed in. It does not read, collect or post anything for other TikTok users.

Source code: github.com/Ethmaster400/Twitch-Clipper
